## This is a drill, not a book — arguably needs no sheet at all

Type Challenges has no table of contents to mirror: it's a growing,
community-submitted puzzle set (currently ~190+ challenges) organized only
by difficulty tier (warm-up / easy / medium / hard / extreme). There is no
author's chapter order to follow, so rule 1 in `docs/notes/README.md`
("the sheet follows the source's own structure") doesn't really apply here —
there is no structure to inherit beyond the tiers.

This sheet exists mainly so the source isn't undocumented, and to record
solved puzzles and the type-system tricks learned solving them. It should
stay a running log, not a scaffold to fill in — do not pre-list challenges
that haven't been attempted.

---

## How I use this sheet

- One entry per challenge actually attempted, added as solved — not
  scaffolded in advance.
- Format per entry: `### <number> · <title> (<tier>)`, a short note on the
  trick used, and the solution in a ``` fence if worth keeping.
- Open questions: `❓ question`.
