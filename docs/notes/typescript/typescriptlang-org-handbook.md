## How I take notes in this sheet

- Notes follow the source's own structure and order.
- My own words, as if taking notes in class.
- Code I rehearse goes inside ``` fences.
- Questions I can't answer yet: `❓ question`
- One topic per `##` heading, named as the source names it.

This sheet mirrors the Handbook's own left-nav grouping (Get Started / The
Handbook / Reference / Modules / Tutorials / Declaration Files / JS Projects /
Project Configuration), each entry an empty section headed by the page's own
title. The "What's New" release-notes archive is a changelog, not reading
material — it is deliberately left out of this sheet.
