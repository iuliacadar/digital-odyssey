## This is a reference book, not the spine

The Phase 3 spine is the TypeScript Handbook + Beginner's TypeScript
(Total TypeScript) — see `docs/CURRICULUM.md`. This book runs to ~20
chapters and several hundred sub-topics (compiler internals, style guide,
tooling tips) that go well past what a junior needs by week 24. Scaffolding
its entire table of contents here would repeat the mistake already made once
with the C.J. Date sheet: an exhaustive skeleton makes a reference book look
like a planned cover-to-cover read.

So: only the top-level chapters are scaffolded below, empty. Sub-topics are
added as `###` only if and when actually consulted — dipped into for a
specific answer (e.g. "how does TS handle discriminated unions"), not
read start to finish. If a full read-through is ever decided on, expand
this file then, not now.

---

## How I take notes in this sheet

- Notes follow the source's own structure and order.
- My own words, as if taking notes in class.
- Code I rehearse goes inside ``` fences.
- Questions I can't answer yet: `❓ question`
- One topic per `##`/`###` heading, named as the source names it.
